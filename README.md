# Electricity Consumption Dashboard (Excel)

## Project Overview
Developed an interactive Excel dashboard to analyze electricity consumption patterns using raw energy usage data. The project involved cleaning and transforming the dataset, creating PivotTables, and designing an interactive dashboard to identify usage trends across months, weekdays, and time periods.

## Objectives
- Analyze electricity consumption trends.
- Identify daily and monthly usage patterns.
- Create an interactive dashboard for data exploration.

## Tools Used
- Microsoft Excel
- PivotTables
- Pivot Charts
- Slicers
- Conditional Formatting
- Flash Fill
- Data Cleaning Techniques

## Data Preparation
- Cleaned and organized raw electricity consumption data.
- Standardized date and time formats.
- Used Flash Fill to extract and format required fields.
- Removed inconsistencies and prepared the dataset for analysis.

## Dashboard Features
- Monthly electricity consumption analysis.
- Weekday-wise consumption comparison.
- Interactive time-based filtering using slicers.
- Conditional formatting heatmap to highlight high and low consumption periods.
- Sparklines to visualize consumption trends.

## Key Insights
- Electricity usage peaks during specific months of the year.
- Consumption patterns vary significantly across weekdays.
- Evening hours tend to show higher electricity demand.
